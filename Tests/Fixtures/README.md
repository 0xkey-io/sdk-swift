# Cross-language fixtures

Every `*.json` file here is generated by calling the **built sdk-js packages**
(sdk-js `packages/{crypto,encoding,api-key-stamper,webauthn-stamper}/dist`), not
written by hand. Each file has a `_meta` header with `generator`, `generatorCommand`,
`sdk_js_commit` and `generatedAt`.

- Generator: `Scripts/vectors/gen-fixtures.mjs`
- sdk-js commit: `850ef7ef68287d481655b39ab555f181abdc54f8`
- Reproduce and verify (offline):

  ```bash
  SDK_JS_DIR=../sdk-js bash Scripts/vectors/run-all.sh           # verify
  SDK_JS_DIR=../sdk-js bash Scripts/vectors/run-all.sh --update  # regenerate
  ```

  `UPSTREAM_SDK_JS_DIR` (optional) points at an upstream JS SDK checkout to re-read the upstream
  constants of `constants.json`; without it the committed values are kept.
  ```

All keys are synthetic, derived from fixed labels (`sha256("0xkey-sdk-swift-vector:<label>")`).
No production key material, organization or user IDs are present. The enclave signer and
notarizer used to sign the export/import bundles and the session JWT are synthetic too;
tests pass them through `dangerouslyOverrideSignerPublicKey` / `dangerouslyOverrideNotarizerPublicKey`.

| File | sdk-js source exercised | Swift check |
|---|---|---|

| `api-key-stamp.json` | `ApiKeyStamper` (`purejs` runtime, deterministic RFC 6979) | whole `X-Stamp` header byte-for-byte (signature injected) + verification both ways |
| `body-digest.json` | SHA-256 of body, WebAuthn challenge, `stringToBase64urlString` | byte-for-byte |
| `webauthn-stamp.json` | `WebauthnStamper.stamp` with mocked `navigator.credentials.get` | header byte-for-byte, challenge bytes, RP ID pass-through |
| `hpke.json` | `hpkeAuthEncrypt` (fixed sender = deterministic `hpkeEncrypt`), `hpkeEncrypt`, `formatHpkeBuf`, legacy upstream HPKE schedule | encrypt byte-for-byte, decrypt, legacy rejected |
| `credential-bundle.json` | `decryptCredentialBundle` | decrypt |
| `export-bundle.json` | `decryptExportBundle` (mnemonic / hex / SOLANA), 4 negatives rejected by sdk-js | output equality, negatives rejected |
